| Versión | Soportada          |
| ------- | ------------------ |

## Compromiso de Seguridad

MiniaturaYT es una aplicación web estática del lado del cliente.
- No almacena información confidencial en el servidor.
- No implementa APIs de retransmisión o proxies abiertos.
- Las consultas se realizan directamente desde el navegador del usuario hacia los servidores oficiales de YouTube (`i.ytimg.com`).
- No se recopilan ni comparten datos personales, identificadores de sesión ni cookies de seguimiento.

## Reporte de Vulnerabilidades

Si descubres una vulnerabilidad de seguridad en este proyecto:
1. Por favor, abre un Issue privado o envía un correo de contacto antes de publicar un aviso público.
2. Proporciona detalles suficientes para reproducir el problema de forma ética (pasos, URL de prueba, entorno).
3. Evaluaremos y responderemos a los reportes en un plazo menor a 48 horas laborales.
